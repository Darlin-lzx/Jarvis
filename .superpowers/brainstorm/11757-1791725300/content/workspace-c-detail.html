交互与数据规则

Changes

读取当前智能体 project_dir 的 Git working tree。M/A/D/R/U 分色，点击文件看 unified diff；非 Git 工程明确提示，不伪造 diff。

Project

按当前智能体绑定工程懒加载目录树；文件只读预览，路径访问强制限制在 project_dir 内。

Evidence

从会话 trace 中提取 code_read / code_search / rag_search。读过的是 READ，检索命中是 SEARCH；不会标成 Git 修改。

Agent 切换

选中 boot / hall-center / order-center 等智能体时，右侧工作区整体切换到对应 project_dir；未绑定工程显示空状态。
